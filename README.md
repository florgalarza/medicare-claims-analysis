
# Medicare Claims Analysis (2008–2010)

Proyecto realizado para el challenge técnico de Colonia Suiza.

Análisis de datos públicos sintéticos de Medicare (CMS DE-SynPUF), enfocado en la utilización de servicios médicos, los pagos asociados y las características de los beneficiarios.

Herramientas

Python · SQL · Tableau

Análisis

El proyecto incluyó la exploración, limpieza y consolidación de los datos mediante Python, consultas SQL para validar los resultados y el desarrollo de un dashboard interactivo en Tableau.

Se analizaron principalmente:

Utilización y pagos de servicios Inpatient y Outpatient.

Diferencias según cantidad de enfermedades crónicas.

Distribución por grupos etarios y ubicación geográfica.

Evolución de los indicadores entre 2008 y 2010.

Dashboard

Ver tablero interactivo en Tableau Public

El tablero reúne una selección de los indicadores y hallazgos del proyecto. No se incluyeron todas las variables ni todos los análisis exploratorios realizados, con el objetivo de mantener una visualización clara y enfocada en las principales comparaciones.

El detalle del procesamiento y las validaciones puede consultarse en el notebook de Python y en las consultas SQL disponibles en este repositorio.

Consideraciones

Los datos utilizados son sintéticos y los resultados tienen un alcance descriptivo. Se aplicaron criterios de exclusión para determinados registros con información insuficiente y las diferencias de cobertura entre años limitan algunas comparaciones temporales.
