
# Medicare Claims Analysis (2008–2010)

Proyecto realizado para el challenge técnico de **Colonia Suiza**.

Análisis de datos públicos sintéticos de Medicare (2008–2010), enfocado en la utilización de servicios médicos, los costos asociados y su evolución.

**Herramientas:** Python, SQL y Tableau.
